Key Features

End-to-end customer intelligence platform with machine learning, interactive dashboards, and AI-powered recommendations.

JWT Authentication

Secure login with bcrypt password hashing, JWT tokens, and role-based access (Admin, Manager, Analyst).

Customer Management

Full CRUD with search, pagination, filtering, profile pages, and purchase history tracking.

Analytics Dashboard

Real-time KPIs — total customers, churn rate, retention rate, revenue, CLV, with interactive charts.

K-Means Segmentation

Unsupervised clustering into High Value, Frequent, Occasional, and At-Risk customer segments.

Churn Prediction

3 ML models — Logistic Regression, Random Forest, XGBoost — with probability scoring and risk levels.

AI Recommendations

Retention strategies, discount suggestions, loyalty programs, and win-back campaigns per customer.

CLV Prediction

Gradient Boosting model predicts future revenue and classifies customers into Platinum/Gold/Silver tiers.

Report Generation

PDF and Excel reports with customer analytics, churn analysis, segmentation data, and CLV breakdowns.

MySQL Database

10 normalized tables with indexes, views, foreign keys, and audit logging for complete data integrity.

System Architecture

Three-tier architecture with async API, React frontend, and MySQL database.

Quick Start

1 Clone & Setup Database

# Clone the repository
git clone https://github.com/your-username/customer-intelligence.git
cd customer-intelligence

# Setup MySQL database
mysql -u root -p < database/schema.sql

2 Backend Setup

cd backend
python -m venv venv && source venv/bin/activate
pip install -r requirements.txt
cp .env.example .env

# Generate sample data & train models
python ../scripts/generate_sample_data.py
python ml/scripts/train_all.py

# Start server
uvicorn app.main:app --reload --port 8000

3 Frontend Setup

cd frontend
npm install
npm run dev

# Frontend: http://localhost:5173
# API Docs: http://localhost:8000/api/docs

🐳 Docker Deployment (Alternative)

docker-compose up -d

# Frontend: http://localhost:3000
# Backend API: http://localhost:8000
# MySQL: localhost:3306
